# CitySim 수동 점검 체크리스트 (건설/보관함/생산수령/이동/판매)

## 공통 사전 조건
- 시티 화면 진입 후 `city-grid`가 정상 렌더링된다.
- 자금이 2,000 이상인 상태에서 시작한다.
- 기존 저장 데이터가 있으면 동일 계정으로 로드 후 테스트한다.

## 1) 빌드(건설) 흐름
1. 건설 버튼을 눌러 건설 패널을 연다.
2. `병영` 또는 `도로` 카드를 선택한다.
3. 맵 타일을 클릭해 배치한다.
4. 같은 타일에 재배치(비용 중복 여부)와 배치 불가 타일(겹침)도 확인한다.

기대 결과
- 컨텍스트 바가 `... 배치 모드`로 표시된다.
- 배치 가능/불가 사유가 힌트로 즉시 반영된다.
- 배치 성공 시 타일 반영 + 힌트가 `... 배치 완료` 또는 `... 적용 완료`로 바뀐다.
- 자금 부족 시 배치되지 않고 부족 메시지가 출력된다.

## 2) 보관함 패널 흐름
1. 보관함 버튼으로 보관함 패널을 연다.
2. 건설 패널/미션 패널/상점이 동시에 열리지 않는지 확인한다.
3. 보관함을 닫았다가 다시 열어 상태가 유지되는지 확인한다.

기대 결과
- 보관함 열기 시 건설/미션/상점이 닫힌다.
- 보관함 탭/카드가 정상 렌더링된다.
- 보관함 오픈/클로즈 시 컨텍스트 바가 비정상 고정되지 않는다.

## 3) 생산/수령 흐름
1. 병영/공장/연구소/공항/보급창고 중 생산 건물을 선택한다.
2. `기능` 버튼으로 생산 UI를 열고 유닛 생산을 시작한다.
3. 생산중 배지를 확인한다.
4. 완료 후 건물 위 `수령` UI 또는 컨텍스트 `수령` 버튼으로 수령한다.

기대 결과
- 생산 시작 시 자금 차감 + 쿨다운 표시가 생긴다.
- 완료 시 `수령` 상태로 바뀐다.
- 수령 시 보관함 수량이 증가하고 생산 대기열이 비워진다.
- 생산 건물 제거/이동 시 비정상 큐가 남지 않는다.

## 4) 이동 흐름
1. 이동 가능한 건물을 선택한다(사령부 제외).
2. 컨텍스트 `이동` 클릭 후 목표 타일을 선택한다.
3. 비용 부족 상태에서도 동일 시나리오를 확인한다.

기대 결과
- `... 이동 모드`와 비용 안내가 표시된다.
- 이동 성공 시 건물이 목표 위치로 이동하고 원위치가 비워진다.
- 이동 비용이 차감되고 선택 상태가 새 위치로 옮겨진다.
- 비용 부족/겹침/형태 불일치 시 이동되지 않고 사유가 노출된다.

## 5) 판매(철거) 흐름
1. 판매 가능한 건물을 선택한다.
2. 컨텍스트 `판매` 클릭 후 제거 결과를 확인한다.
3. 연병장/풋프린트 건물(공항/공원 2x2 포함)도 각각 확인한다.

기대 결과
- 선택 건물이 제거되고 그리드가 즉시 갱신된다.
- 연병장 유닛은 보관함으로 반환된다.
- 풋프린트 건물은 관련 타일이 일괄 정리된다.
- 사령부는 판매 불가 메시지가 표시된다.

## 회귀(필수)
- 건설 패널을 렌더 호출만으로 다시 그릴 때 선택 상태가 임의로 풀리지 않는다.
- 컨텍스트 바 버튼 라벨/활성 상태가 현재 상태(선택/배치/이동)에 맞게 바뀐다.
- 브러시 배치 중 자동 저장 지연(`_cityBrushDirty`)이 깨지지 않는다.

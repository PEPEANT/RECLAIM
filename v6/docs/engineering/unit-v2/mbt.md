# Unit Render V2 스펙: mbt

## 1) 기본 정보
- `unitId`: `mbt`
- `상태`: `planned`
- `담당`: TBD
- `최종 수정일`: 2026-02-21

## 2) 범위
- 이번 단계에서 바꾸는 것:
- MBT 렌더러 V2 교체
- 플레이어 조종 포탑 조준/발사/폭발 이펙트 명세 반영
- 이번 단계에서 바꾸지 않는 것:
- 배경/월드 크기 변경
- 타 유닛 렌더 교체

## 4) 고정 필수 요구사항
1. 플레이어 조종 시 포탑 조준 각도 제한 지원
2. 상단 조준 제한은 `-45도` 기준 유지
3. 좌/우 방향 모두 포탑 발사 가능
4. 신규 포구 화염/연기 효과 적용
5. 탄착 시 신규 폭발/먼지 효과 적용
6. 발사 -> 비행 -> 충돌 -> 폭발 파이프라인 누락 금지

## 5) 렌더 계약
- `canRender(unit)`:
- `unit.stats.id === 'mbt'`일 때 true
- `draw(unit, ctx, env)`:
- 성공 시 `true` 반환
- 처리 불가/에러 시 `false` 반환 후 레거시 fallback

## 6) 스케일/좌표 정책
- 적용 스케일 토큰: `UNIT_RENDER_SCALE`
- 지면 정렬: 기존 `groundY` 기준 유지
- 초기 단계에서 판정 크기(`width/height`)는 유지

## 7) 기능 플래그
- 플래그 키: `window.RENDER_V2_UNITS.mbt`
- ON: MBT만 V2 경로 사용
- OFF: 즉시 레거시 경로 복귀

## 8) 검증 체크리스트
1. 모든 맵에서 출력 정상
2. 접지 정상 (뜸/묻힘 없음)
3. 포탑 `-45도` 제한 정상
4. 좌/우 조준 및 발사 정상
5. 반동 및 포구 위치 정렬 정상
6. 신규 폭발 이펙트 정상
7. 콘솔 에러 없음
8. 플래그 OFF 롤백 정상

## 9) 알려진 이슈 / 제한
- 초기 단계는 시각 스케일과 판정 스케일이 일시적으로 다를 수 있음

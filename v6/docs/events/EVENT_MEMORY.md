# City Event Memory

이 문서는 이벤트가 추가될 때마다 아래 항목을 기록하는 운영 메모입니다.

## 기록 규칙
- `event_id`: 이벤트 식별자
- `image_path`: 팝업 이미지 경로
- `never_show_key`: `다신열지않음` 저장 키
- `quest_ids`: 연동된 이벤트 퀘스트 ID
- `rewards`: 퀘스트 보상 요약
- `notes`: 특이사항

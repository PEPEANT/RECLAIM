# 튜토리얼 개발 계획서 (v1)

- 작성일: 2026-02-20
- 대상 버전: `RECLAIM v6`
- 목표: 처음 접속한 유저가 `로비 -> 시티 -> 전투` 핵심 흐름을 5~8분 안에 이해하고 1회 완료

## 1. 범위 정의

### 포함
- 로비 기본 조작 (로그인/게스트, 시작 버튼)
- 시티 기본 조작 (건물/보관함/출격 진입)
- 전투 기본 조작 (유닛 선택, 이동, 공격, 후퇴)
- 완료 보상/재진입 시 처리 (튜토리얼 완료 플래그)

### 제외 (2차)
- 고급 전술(정찰, 미사일 세부 운용)
- 베테랑/아이템 세팅 심화
- 캠페인 전체 설명

## 2. 성공 기준 (DoD)

1. 신규 유저가 튜토리얼 목표 단계(최대 10단계)를 순서대로 완료 가능
2. 단계별 안내가 누락되지 않고, 중간 이탈 후 재접속 시 단계 복구
3. 튜토리얼 스킵/재시작 동작이 정상
4. 튜토리얼 중 검은 화면/입력 잠김 같은 블로킹 버그 없음

## 3. 튜토리얼 단계 설계

## Lv.1 첫 시티 진입 튜토리얼 오버레이 (영상 + 선택지)

### 트리거
- 조건: `플레이어 레벨 == 1` AND `첫 시티 진입` AND `tutorial_city_intro_seen == false`
- 발생 시점: 시티 UI 로딩 완료 직후(전투 버튼 노출 이후)

### UI 배치
- 전투 버튼 왼쪽 영역에 튜토리얼 패널 노출
- 패널 구성:
  - (좌) 동영상 재생 영역(자동재생, 기본 음소거 + 자막 ON 권장)
  - (좌하/우하) 선택 버튼 2개
- 선택 버튼 문구:
  - [튜토리얼 진행을 들어보겠다]
  - [들을 필요 없다]

### 동작
- [튜토리얼 관련 진행을 들어보겠다]
  - 영상 재생 유지 + 안내장교 대사/하이라이트(경제 건물 -> 상점/보관함 -> 퀘스트 흐름)
  - 완료 시 `tutorial_city_intro_seen = true`
- [들을 필요없다.]
  - 오버레이 즉시 닫기
  - `tutorial_city_intro_seen = true` 저장(재노출 방지)
  - 메뉴/설정에 “튜토리얼 다시보기” 버튼 제공 권장

### 예외/안전장치
- 네트워크/영상 로드 실패 시: 영상 대신 “요약 텍스트” 표시 + 동일한 2버튼 제공
- 모바일/저사양 고려: 자동재생은 음소거로 시작, 사용자가 누르면 소리 ON

### 첫시작(처음인사) 상세 시나리오

#### 목적
- 첫 진입 유저에게 “지금 무엇을 해야 하는지”를 30~60초 안에 명확히 전달
- 튜토리얼 수락/거절을 즉시 선택하게 해서 흐름 분기 확정

#### 진입 조건
- `playerLevel == 1`
- `tutorial_city_intro_seen == false`
- `city-screen` 렌더 완료 상태

#### 화면 상태(노출 직후)
- 전투 버튼 왼쪽에 튜토리얼 패널 표시
- 배경 UI는 클릭 가능하되, 핵심 버튼 외 나머지는 반투명 처리 권장
- 오버레이 최상단 문구 예시:
  - `사령관님, 시티 운영 기본 절차를 1분 안에 안내하겠습니다.`

#### 대사/안내 순서(초기)
1. 인사: `사령관님, 도시 운영 지휘를 시작합니다.`
2. 목적: `자원 확보 -> 병력 준비 -> 전투 투입 순서로 진행합니다.`
3. 영상 자동재생 종료 후 선택 버튼 표시
4. 선택 유도: `지금 바로 튜토리얼을 들을지 선택해 주세요.`

#### 선택 버튼 동작(확정)
- [튜토리얼 진행을 들어보겠다]
  - `tutorial.mode = guided`
  - step 1(처음인사) 시작
  - 다음 단계(경제)로 자동 전이 준비
- [들을 필요 없다]
  - 오버레이 닫기
  - `tutorial_city_intro_seen = true`
  - `tutorial.skipped = true`
  - 재노출 방지 처리

#### step 1 -> step 2 전환(요청 반영)
- 수락 버튼 클릭 즉시 step 2(경제) 안내 시작
- 안내 문구 예시: `이제 건설 버튼을 눌러 기초 경제를 시작하십시오.`
- 동작:
  - 건설 관련 버튼만 강조 표시(펄스/외곽선)
  - 나머지 버튼은 비강조(필요 시 입력 잠금)
  - 건설 버튼 1회 클릭 시 step 2 완료

#### 완료 처리
- 수락/거절 중 하나를 누른 즉시 step 1 완료로 기록
- 저장:
  - 로컬 상태 즉시 반영
  - 저장 루틴(로컬/클라우드) 큐에 반영

#### 실패/예외 처리
- 영상 로드 실패: 안내 텍스트 모드로 자동 전환 (버튼은 동일)
- 15초 이상 입력 없음:
  - 패널 강조(펄스) 1회
  - 그래도 무응답이면 상태 유지(강제 진행 금지)

## 10단계 확장형 진행 구조 (최대 10단계)

- 운영 기준: `step 1 ~ step 10` 고정 슬롯으로 설계
- 장점:
  - 긴 튜토리얼에서도 순서 제어가 단순함
  - 중간 저장/복구/건너뛰기 구현이 쉬움
  - 단계 추가/삭제 시 데이터 구조를 거의 건드리지 않음

### 단계 권장 분할(예시)
- step 1: 처음인사
- step 2: 경제
- step 3: 병영 + 유닛뽑기
- step 4: 퀘스트
- step 5: 상점 + 보급상자
- step 6: 보관함
- step 7: 특수유닛 + 적용
- step 8: 전투
- step 9: 전투실시
- step 10: 튜토리얼마침

### 단계 데이터 공통 필드
- `id` (1~10)
- `title`
- `description`
- `trigger` (진입 조건)
- `completeWhen` (완료 조건)
- `highlightTargets` (하이라이트 대상 DOM 키)
- `allowSkip` (스킵 허용 여부)

### T0. 시작 안내
- 진입 조건: 첫 로그인(또는 튜토리얼 미완료)
- 안내: 튜토리얼 시작/건너뛰기 선택

### T1. 시티 진입 및 기본 UI 인지
- 목표: 처음인사 영상 시청 후 수락/거절 선택
- 완료 조건: 두 선택 버튼 중 하나 클릭

### T2. 경제 시작
- 목표: 경제 시작(건설 버튼 진입)
- 완료 조건: 건설 관련 버튼 1회 클릭

### T3. 전투 조작
- 목표: 선택/이동/공격 1회씩 수행
- 완료 조건:
  - 유닛 선택 1회
  - 이동 명령 1회
  - 교전 발생(또는 공격 명령 1회)

### T4. 전투 종료/후퇴
- 목표: 후퇴 또는 전투 종료 흐름 학습
- 완료 조건: 후퇴 버튼 실행 후 시티 복귀

### T5. 완료 처리
- 목표: 튜토리얼 완료 저장
- 완료 조건: `tutorial.completed = true` 저장 + 재진입 시 미노출

## 4. 구현 구조 제안

- 상태 저장:
  - `citySim.tutorial = { completed, skipped, step, maxStep, updatedAt, tutorial_city_intro_seen }`
  - 권장 기본값: `step=0`, `maxStep=10`, `completed=false`
- 진입 훅:
  - 로그인 완료 후 / 시티 진입 시 튜토리얼 상태 검사
- UI:
  - 상단 안내 배너 + 단계별 하이라이트 + 다음 버튼
- 안전장치:
  - 화면 전환 시 단계 유효성 재검증
  - 타임아웃/에러 시 안전 복귀 (시티 화면)

### 코드 분리 권장 (긴 튜토리얼 대응)
- `src/modes/city-sim/tutorial/index.js` : 외부 진입점/초기화
- `src/modes/city-sim/tutorial/flow.js` : 1~10 단계 전이 로직
- `src/modes/city-sim/tutorial/steps.js` : 단계 정의 데이터(문구/조건)
- `src/modes/city-sim/tutorial/ui.js` : 오버레이/하이라이트 렌더
- `src/modes/city-sim/tutorial/state.js` : 저장/복구/완료 플래그 관리

## 5. 작업 순서

1. 데이터 스키마 추가 (`tutorial` 상태)
2. 1~10 단계 정의 파일(`steps.js`) 작성
3. 튜토리얼 엔진(단계 전이/조건 검사) 구현
4. 단계별 UI 오버레이/하이라이트 구현
5. 시티/전투 이벤트 연결 (선택/이동/후퇴 감지)
6. 저장/복구/스킵 처리
7. 회귀 테스트 + 문서 업데이트

## 6. 테스트 체크리스트

- 신규 계정: 튜토리얼 자동 시작 여부
- 게스트 계정: 시작/스킵/재진입
- Lv.1 첫 시티 진입: 영상+2버튼 오버레이 노출 여부
- 오버레이 버튼별 처리: [튜토리얼 관련 진행을 들어보겠다] / [들을 필요없다.] 저장 플래그 검증
- 단계 중 앱 새로고침: 단계 복구
- 시티 -> 로비 -> 시티 반복: 단계 유실/검은 화면 여부
- step 1~10 순차 진행 중 점프/역행 없이 정상 전이되는지
- step 10 완료 후 `completed=true` 저장 및 재진입 미노출
- 튜토리얼 완료 후: 재노출 안됨

## 7. 리스크 및 대응

- 리스크: UI 전환 충돌로 안내 오버레이 잔존
  - 대응: 화면 전환마다 오버레이 강제 정리
- 리스크: 단계 조건 미충족으로 진행 정지
  - 대응: 디버그 강제 다음 단계 명령 제공
- 리스크: 저장 실패로 완료 플래그 유실
  - 대응: 완료 즉시 로컬 + 클라우드 동시 저장 시도

## 0) 사전 준비
- [ ] 브라우저 강력 새로고침(`Ctrl+F5`) 1회
- [ ] 콘솔 에러 패널 비우기

## 1) P0 - 설정 > 후퇴 모달 즉시 닫힘 회귀 확인
시나리오:
1. 전투 시작
2. 설정 열기
3. `후퇴` 클릭
4. 확인창 유지 여부 확인
5. `취소` 클릭
6. 다시 `후퇴` -> `확인`

체크:
- [ ] `후퇴` 클릭 시 확인창이 바로 닫히지 않는다
- [ ] `취소` 시 전투 유지된다
- [ ] `확인` 시 시티로 정상 복귀한다
- [ ] 반복 3회에서도 동일하다

## 2) P0 - 도시 소탕전(101) 프리셋 검증
요구 상태:
- 아군: `special_ops 4`, `humvee 6`
- 적군: `humvee 5` (도시소탕전 전용 스킨)

체크:
- [ ] 스테이지 101 시작 직후 아군 `특수부대 4` 확인
- [ ] 스테이지 101 시작 직후 아군 `험비 6` 확인
- [ ] 스테이지 101 시작 직후 적군 `험비 5` 확인
- [ ] 적 험비 스킨이 도시소탕전 전용으로 표시된다

## 3) P0 - 진격전(104) 탱크 추가/겹침 완화 검증
요구 상태:
- 적 `MBT 15`
- 과도한 한점 겹침 없음(분산 배치)

체크:
- [ ] 스테이지 104 시작 직후 적 `MBT` 총 15기 확인
- [ ] 탱크가 초기 배치에서 과도하게 겹쳐 있지 않다
- [ ] 전투 시작 후 즉시 충돌/튕김 없이 진행된다

## 4) 스모크 회귀
- [ ] 설정창 열기/닫기 반복 5회 정상
- [ ] 전투 종료 후 로비/시티 전환 정상
- [ ] 콘솔 치명 에러(uncaught) 없음

## 5) 합격 기준 (Go / No-Go)
- [ ] 1~3 섹션 모든 항목 통과
- [ ] 콘솔 치명 에러 없음

판정:
- [ ] GO (배포 진행)
- [ ] NO-GO (배포 보류, 핫픽스 필요)

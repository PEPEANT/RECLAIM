# Mobile Combat HUD Rules (One Pager)

목표: 전투 중 상시 UI를 최소화하고, 명령 입력 정확도와 전장 가시성을 동시에 확보한다.

## 1. 상시 노출 원칙
1. 전투 중 상시 UI는 `2개`만 유지한다.
2. 상시 UI 구성은 `미니맵(소형)` + `명령바(대형 6버튼)`이다.
3. `유닛 생성바`는 상시 노출 금지한다.
4. 생성 UI는 `HQ/생산 건물 선택 시`에만 Bottom Sheet로 노출한다.

## 2. 레이아웃 규칙
1. 좌하단: 미니맵 고정.
2. 하단 중앙~우측: 명령바 6칸 고정.
3. 우상단: 설정/옵션 단일 버튼 유지.
4. Bottom Sheet는 화면 하단에서 올라오며 명령바 위 레이어로 표시한다.

## 3. 명령바 버튼 규격
1. 기본 슬롯 수: `6`.
2. 슬롯 구조: 고정 4칸 + 컨텍스트 2칸.
3. 버튼 최소 터치 영역: `56x56px` (절대 최소 `48x48px`).
4. 버튼 간 간격: `8px`.
5. 버튼 라벨: 1줄, 10~12px, 아이콘 우선.
6. 상태: `normal`, `active`, `disabled`, `cooldown`.
7. disabled는 명도 60% 이하 + 입력 차단.
8. cooldown은 버튼 상단 원형/선형 오버레이로 남은 시간 표기.

## 4. 권장 6칸 매핑
1. `취소` (조준 취소/선택 해제/복구)
2. `태세` (전진/홀드/후진 3단 토글)
3. `스킬1` (유닛/건물 컨텍스트)
4. `스킬2` (유닛/건물 컨텍스트)
5. `인터랙트` (탑승/하차/설치/회수/배치)
6. `더보기` (보조 명령 확장)

## 5. 생성 UI(Bottom Sheet) 규칙
1. 자동 오픈: HQ/생산 건물 선택 직후.
2. 자동 닫힘: 유닛 선택, 빈 타일 선택, 전투 입력 시작, 뒤로가기.
3. 시트 높이: 화면 높이의 `42~55%`.
4. 카테고리 탭: 보병/기갑/공중(필요 시 특수).
5. 목록은 가로 스크롤 가능, 카드는 최소 `88x88px`.
6. 시트 오픈 중에도 미니맵은 유지한다.

## 6. 미니맵 규칙
1. 기본 크기: 기존 대비 `50~66%`.
2. 탭 동작: 소형 <-> 확대 오버레이 토글.
3. 확대 중에는 명령바 입력을 잠시 잠그거나 투명도 60%로 낮춘다.
4. 미니맵 드래그/탭 이동 우선순위는 전장 터치보다 높다.

## 7. 애니메이션/타이밍 규칙
1. 공통 easing: `cubic-bezier(0.22, 0.61, 0.36, 1)`.
2. 명령바 상태 전환: `120ms`.
3. Bottom Sheet 열림: `180ms`.
4. Bottom Sheet 닫힘: `160ms`.
5. 미니맵 확대/축소: `140ms`.
6. 선택 변경 후 시트 오픈 지연: `50ms` (의도치 않은 깜빡임 방지).
7. 연속 선택 이벤트 디바운스: `80ms`.

## 8. 입력 충돌 방지 규칙
1. `한 프레임 한 컨텍스트` 원칙을 적용한다.
2. 시트 열림 중 전장 터치가 들어오면 시트 우선 닫힘 처리 후 전장 입력 처리.
3. 조준 모드 진입 시 시트는 강제 닫힘.
4. 드래그 시작 임계값: `8px` (터치), `4px` (마우스).

## 9. 모바일 안전영역 규칙
1. 하단 패딩: `env(safe-area-inset-bottom)` 필수 반영.
2. 상단/좌우도 `safe-area` 기준으로 버튼이 잘리지 않게 배치.
3. 높이 계산은 `100dvh + visualViewport` 보정값을 우선 사용.

## 10. 예외 모드 규칙
1. 국지전/점령전 프리배치 단계는 전투 HUD와 별도 모드로 분리한다.
2. 프리배치 중 Bottom Sheet 자동 오픈 로직을 비활성화한다.
3. 모드 종료 후 HUD 상태를 `기본(2개 상시)`로 복귀한다.
